Open Weights Index

The current release of every open-weights model Artificial Analysis benchmarks, joined to the machine-readable model card each lab publishes on the Hugging Face Hub. Parameter counts, context windows and licences come from the cards themselves; the score is the Artificial Analysis Intelligence Index, at the model's best reasoning setting.

No model matches those filters.

What counts as current

One row per release, not per checkpoint. Reasoning-effort variants of the same model collapse into a single row scored at its best setting — the spread is in the detail panel. A release drops off when its own lab ships something newer and better in the same size class, so what remains is each lab's live lineup.

Reading the score

The Intelligence Index is a composite of nine evaluations run independently by Artificial Analysis; the detail panel breaks out the components. It is a measure of capability, not of cost or speed — and not of openness, which the openness figure tracks separately.

Sources

Cards: huggingface.co/api/models/<repo> plus the YAML front matter of each card and its config.json. Scores: artificialanalysis.ai. Parameter totals are summed from the safetensors index, so they are the shipped weights rather than a rounded marketing figure.
